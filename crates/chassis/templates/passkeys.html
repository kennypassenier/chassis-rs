Passkeys

A passkey lets you open this dashboard from your password manager (Bitwarden, the browser's own store) without typing the login token. Register one here while logged in; from then on the login page shows a passkey button. The token keeps working as the fallback. Browsers only allow passkeys over HTTPS, so this page is live only when you reach the dashboard through the TLS proxy named in {{ prefix }}_PUBLIC_URL.
